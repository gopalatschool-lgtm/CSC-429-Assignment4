# Laptop Advisor Expert System

## 1. Project Overview

 I created a Laptop Advisor expert system using Python. The purpose of the program is to recommend laptop types and specifications based on the user's needs and preferences.

When the program starts, it asks questions about the user's budget, portability, battery life, gaming, creative work, and operating system preference. Based on the answers, it uses a knowledge base of IF-THEN rules to generate recommendations.

The system uses forward chaining to make decisions.

## 2. Project Structure

The project contains the following main files:

- `main.py` - Handles user input, runs the expert system, and displays the results.
- `engine.py` - Contains the forward-chaining inference engine.
- `kb/laptop_rules.json` - Contains the 10 IF-THEN rules used by the system.
- `tests/test_engine.py` - Contains unit tests for checking the rules and inference engine.

## 3. How the System Works

The program first collects facts from the user. For example, a user might have a low budget, need portability, and want long battery life.

These facts are stored and passed to the inference engine.

The engine checks the conditions of each rule in the knowledge base. If all conditions of a rule are satisfied, the rule fires and its conclusion is added to the results.

This process is called forward chaining. The system continues checking rules until no more rules can fire.

The engine uses three main functions:

- `can_fire(rule)` checks whether all conditions of a rule are satisfied.
- `run()` repeatedly checks and applies rules using forward chaining.
- `conclusions()` collects the recommendations and specifications generated by the system.

## 4. Knowledge Base

I added 10 rules to the knowledge base:

| Rule | Conditions | Conclusion |
|---|---|---|
| 1. Premium Ultrabook | High budget, portable, long battery | Premium ultrabook |
| 2. Student Light Office | Low budget, office use, portable | Budget ultrabook |
| 3. Gaming Laptop | Gaming, medium budget | Midrange gaming laptop |
| 4. Professional Gaming | Gaming, high budget | High-end gaming laptop |
| 5. Creative Work RAM | Creative work, portable | 16 GB or more RAM |
| 6. Creative Work Display | Creative work, large screen | 15-inch or larger color-accurate display |
| 7. Travel Battery | Frequent travel, long battery | Battery capacity of 60 Wh or more |
| 8. macOS Preference | macOS preference | macOS required |
| 9. AI Acceleration | Needs AI acceleration | GPU with Tensor Cores |
| 10. Linux Compatibility | Linux preference, office use | Linux-friendly hardware |

## 5. Testing

I created a test file called `test_engine.py` inside the `tests` folder.

It contains 11 unit tests:
- 10 tests to check each rule individually.
- 1 additional test to check that no conclusions are generated when no rules match.

I ran the tests using:

```bash
python3 -m unittest discover -s tests -v
```

All 11 tests passed successfully.

```text

OK
```
